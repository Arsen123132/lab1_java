# Music Disc

Лабораторна робота 1, варіант 5 «Звукозапис».

Консольний додаток: ієрархія музичних композицій, запис збірки на диск,
підрахунок тривалості, перестановка за стилем, пошук за довжиною треку.

## Можливості

- ієрархія композицій: `Composition` → `Song`, `InstrumentalPiece` →
  `ClassicalPiece`;
- запис збірки на диск з обмеженням ємності (за замовчуванням 80 хвилин);
- підрахунок загальної тривалості та вільного місця;
- перестановка композицій за стилем (порядок стилів задає `MusicStyle`);
- пошук композицій за діапазоном довжини треку;
- композиції та параметри запуску зберігаються у файлах.

## Структура

| Пакет | Призначення |
|-------|-------------|
| `model` | композиції та стилі |
| `disc` | диск: запис, тривалість, сортування, пошук |
| `io` | читання композицій з CSV |
| `service` | запис композицій із джерела на диск |
| `config` | параметри з `app.properties` |
| `util` | форматування та розбір тривалості |
| `app` | точка входу та сценарій програми |

## Файли даних

- `data/compositions.csv`: композиції у форматі
  `type;title;artist;duration;style;detail;composer`
  (`SONG`, `INSTRUMENTAL`, `CLASSICAL`; тривалість у форматі `m:ss`);
- `data/app.properties`: назва та ємність диска, файл з композиціями,
  діапазон довжини для пошуку.

## Запуск

Потрібні JDK 25 та Maven.

    mvn clean verify
    chcp 65001
    java -Dstdout.encoding=UTF-8 -cp target/classes ua.lab.musicdisc.app.Main

Звіт покриття тестами: `target/site/jacoco/index.html`.
